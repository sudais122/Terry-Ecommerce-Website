 eCommerce Website (Frontend + Basic Backend)

A responsive eCommerce web application built using **HTML, CSS, and JavaScript**, with basic backend functionality using **Node.js**.
This project focuses on building a functional shopping interface while gradually integrating backend features.

---
Overview

This is a learning-based project where I implemented the core structure of an eCommerce website, including product listings, UI interactions, and initial backend setup. The goal is to understand how front-end and back-end systems connect in real-world applications.

---

Features

* Fully responsive design (mobile, tablet, desktop)
* Product listing and UI layout
* Navigation between pages
* Basic cart interaction (frontend logic)
* Dynamic behavior using JavaScript
* Initial backend setup with Node.js

---

#Tech Stack

**Frontend**

* HTML5
* CSS3 (Flexbox, Grid, Media Queries)
* JavaScript (DOM manipulation, basic logic)

**Backend (Basic)**

* Node.js
* Express.js (basic server setup)
